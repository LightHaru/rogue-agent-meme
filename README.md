An original single-panel image meme for make.fun's "Meme Sprint 3: AI Agent Goes Rogue". One dependency-free Node script draws the whole thing pixel by pixel — original bitmap type, hand-built raster art, and a tiny PNG encoder — and writes `entry.png`.

## Run it

```sh
node main.ts           # writes /output/entry.png
node main.ts <dir>     # writes <dir>/entry.png
node --test            # smoke suite
```
